# 🌐iRepair (Landing Page)

Uma landing page moderna e responsiva desenvolvida para apresentar uma agência de assistência de forma profissional.  
O projeto foi criado com foco em usabilidade, design adaptável e interações dinâmicas durante a navegação.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3 (Bootstrap)
- JavaScript

---

## 🎯 Funcionalidades

- Layout 100% responsivo  
- Interface moderna e de fácil navegação  
- Transição suave entre seções  
- Animações acionadas durante o scroll  
- Exibição dinâmica de elementos na navegação  
- Alteração automática de textos utilizando JavaScript (input)  
- Limpeza automática dos campos de formulário ao clicar  

---

## 📱 Responsividade

O projeto foi desenvolvido utilizando conceitos de responsividade para oferecer uma boa experiência em diferentes dispositivos:

- Desktop
- Tablets
- Smartphones

---

## ⚙️ Recursos em JavaScript

O JavaScript foi aplicado para:

- Criar animações durante a rolagem da página
- Exibir elementos de forma dinâmica
- Alterar conteúdos automaticamente
- Limpar os campos dos formulários durante a interação do usuário
